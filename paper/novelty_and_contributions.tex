%  WHY THE PAPER WAS REFRAMED (Phase I)
%  ------------------------------------
%  Before:  "We apply a Gaussian Mixture Model for state identification
%            and an LSTM for forecasting."
%  Problem: reads as an application of two off-the-shelf models, and
%           invites the reviewer question "what is new here?" with no
%           defensible answer.
%  After:   a unified framework whose three stages are designed against
%           each other's requirements -- inference constrained to be
%           temporally coherent because forecasting is otherwise
%           ill-posed; forecasting constrained to predict duration
%           because the decision stage consumes a duration.
%
%  Three additions were made beyond the plan's replacement text, and
%  each has since earned its place:
%
%   1. A reframed abstract, because the old framing also lived there and
%      that is what a reviewer reads first.
%   2. An explicit scope-of-claim paragraph.  Stating "we claim no
%      novelty in the GHMM, the sequence model, or the break-even
%      criterion" before a reviewer does converts the paper's weakest
%      attack surface into evidence of self-awareness; without it,
%      "these are all off-the-shelf components" is the obvious
%      desk-reject line.
%   3. A contribution list in which each item names the experiment that
%      substantiates it.  Contributions a reviewer cannot trace to a
%      table are read as claims, not contributions.
%
%  WHAT LATER PHASES CHANGED, AND WHY
%  ----------------------------------
%  Phase II  (Task 4b/4c) -- contribution 1 originally claimed that
%      jointly learning emissions and transitions reduced flicker by an
%      order of magnitude.  Both halves were wrong: joint emission
%      fitting converges worse than warm-starting from the GMM, and the
%      HMM alone takes flicker from 66.9% only to 44.5%.  The claim is
%      now the bounded-transition-cost result, and the credit for
%      removing flicker goes to the minimum-dwell constraint.
%
%  Phase III (Task 7) -- contribution 4 originally promised "break-even
%      sensitivity across electricity tariff and restart energy".  The
%      tariff axis is degenerate: when the restart cost is purely
%      electrical the tariff cancels in the break-even identity, so
%      every column of the planned heat-map is identical.  The claim is
%      now the invariance result plus a sweep over the axes that carry
%      information.
%
%  Phase V   (Task 11A/12A) -- contribution 3 originally proposed the
%      Seq2Seq LSTM as the forecasting component.  It is beaten by an
%      untrained persistence reference by 7.95 s of per-window MAE.
%      The component is now a gradient-boosted tree, the sequence
%      models are reported as compared baselines, and the negative
%      result is itself part of the contribution.
%
%  Phase V   (Task 12B) -- the physics accept/reject loop was promoted
%      from an implementation detail to a named contribution, because
%      3 seeds in 10 fail it and conditioning on it is what makes the
%      headline state-time total reproducible (CV 33.7% -> 3.0%).
%
%  Phase VI  (Task 13A) -- the "94.5% of the forecaster is calendar"
%      figure was split gain.  Under Shapley attribution it is 82.4%,
%      and gain is misranking the model badly enough that the
%      correction is worth making explicitly.  The conclusion drawn
%      from it is unchanged.
%
%  Phase VII -- the forward references to a sustainability section and
%      a deployment section were removed rather than left dangling.
%      Neither analysis is in this paper; promising them in the
%      contribution list and not delivering them is worse than not
%      promising them.
% =====================================================================
